رمز QRQR code

كيف تعمل؟How it works

  1. الصق الرابط أو النص.Paste the link or text.
  2. أضف عنوانًا فوق الرمز إن أردت.Add a caption above the code if you like.
  3. حمّل صورة PNG للعروض، أو SVG للطباعة.Download a PNG for slides, or an SVG for print.

أسئلة شائعةCommon questions

هل تنتهي صلاحية الرمز؟Does the code expire?

لا. الرمز يحمل الرابط نفسه دون وسيط.No. The code holds the link itself, with no redirect.

كيف أضع عدة ملفات في رمز واحد؟How do I put several files in one code?

ضعها في مجلد على Google Drive أو OneDrive بمشاركة «أي شخص لديه الرابط»، ثم حوّل رابط المجلد إلى رمز.Put them in a Google Drive or OneDrive folder shared with anyone who has the link, then turn the folder link into a code.
