محرر PDFPDF editor

كيف تعمل؟How it works

  1. اختر ملفات PDF أو صورًا، واحدًا أو أكثر.Choose one or more PDFs or photos.
  2. اكتب على الصفحات، وضع علامات ✓ و✕ لتعبئة النماذج، وأضف توقيعك أو صورة أو ختمًا.Write on pages, add ✓ and ✕ marks to fill forms, and add your signature, an image or a stamp.
  3. أخفِ نصًا قديمًا بمربع يأخذ لون الصفحة، واكتب بدله.Cover old text with a box that takes the page colour, and write over it.
  4. ارسم بقلم ناعم، وظلّل النص، وأضف خطوطًا وأسهمًا ومستطيلات ودوائر.Draw with a smooth pen, highlight text, and add lines, arrows, rectangles and circles.
  5. رتّب الصفحات من اللوحة الجانبية، ودوّرها أو احذفها، ثم احفظ ملفًا واحدًا.Arrange, rotate or delete pages from the side panel, then save one file.
  6. عند الحفظ يمكنك تصغير حجم الملف ليسهل إرساله.When saving, you can make the file smaller so it is easy to send.

أسئلة شائعةCommon questions

هل تُرفع ملفاتي إلى خادم؟Are my files uploaded to a server?

لا. تُعالج الملفات داخل جهازك فقط.No. Files are processed on your device only.

لماذا يتلخبط النص العربي عند تحرير PDF في برامج أخرى؟Why does Arabic text break when editing a PDF elsewhere?

لأن الملف يحفظ أشكال الحروف لا الكلمات. هنا يُغطّى النص القديم ويُكتب الجديد بخط سليم.Because a PDF stores letter shapes, not words. Here the old text is covered and the new text is written in a proper font.

كيف أكرر نصًا بالتنسيق نفسه، مثل التاريخ؟How do I repeat text with the same format, such as a date?

اضغط النص ثم «تكرار»، وعدّل النسخة. وفي الحاسب: Ctrl أو ⌘ مع C ثم V.Tap the text, then Duplicate, and edit the copy. On a computer: Ctrl or ⌘ with C, then V.

هل تعمل من الجوال؟Does it work on a phone?

نعم، على الآيفون والأندرويد، ويُحفظ الملف أو يُشارك مباشرة.Yes, on iPhone and Android; the file can be saved or shared directly.
